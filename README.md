# 智光商工 資處一仁 26 號 高于翔 專屬提分網站

## 🎯 專案簡介
本網站是為智光高級商工職業學校 資料處理科 一年仁班 **高于翔同學（座號 26）**量身打造的互動學習與提分系統。
針對旗立發行《數位科技概論（上）隨堂測驗卷 第 3 回：系統平台的組成架構－硬體》（範圍：第 3 章）進行全方位診斷與弱點突破。

---

## 🚀 如何快速開啟網站？
1. **直接開啟**：在資料夾中對 `index.html` 或 `點我開啟複習網站.bat` 連按兩下即可在瀏覽器中暢快使用！
2. **手機連線練習（可選）**：點擊 `啟動本機伺服器(可手機練習).bat`，在同一個 Wi-Fi 下手機輸入電腦 IP 即可在手機上刷題。

## 💎 六大核心提分功能

1. **📊 戰情儀表板 (Dashboard)**
   - 個人成績檔案（本次 76 分 ➔ 目標 100 分）。
   - 弱點雷達與本次 6 大失分題快查。

2. **🎯 錯題死磕精攻 (Mistakes Drill)**
   - 針對考卷扣 24 分的 **6 大錯題（第 15, 16, 17, 19, 22, 24 題）**。
   - 還原考卷上**老師的紅筆批註**（「是28億赫茲」、「不是快取是唯讀記憶體」等）。
   - 深入診斷「為什麼當時會選錯？」。
   - 提供「考前必殺解題公式」。
   - **現場即測即評「雙胞胎變形考題」**，保證考點真正弄懂！

3. **📝 原卷全真模擬考 (Full 25-Question Exam)**
   - 完整收錄原試卷 25 題。
   - 支援「全部25題」、「只練曾錯的6題」、「隨機抽10題」三種模式。
   - 內建計分引擎、題目快速跳轉索引、交卷詳解解析、音效反饋與滿分彩花特效。

4. **⚡ 統測歷屆衝刺題庫 (20 題精選)**
   - 精選四技二專統測商業管理群、資訊電機群「硬體單元」高頻考題（馮紐曼架構、暫存器、RAID、匯流排、中斷等）。

5. **📖 考點必背速記庫 (Cheat Sheets)**
   - 電腦五大單元神口訣。
   - 記憶體存取速度金字塔。
   - SRAM vs DRAM 對比表。
   - ROM 家族演進史與應用（MROM / PROM / EPROM / EEPROM）。
   - 時脈頻率與度量單位換算陷阱大破解（Hz, MHz, GHz, MIPS）。
   - 常用傳輸連接埠一覽（Type-C, HDMI, Line Out, RJ-45）。

6. **🖨️ 紙本測驗卷列印 (Print Exam Mode)**
   - 可一鍵列印成乾淨美觀的 A4 紙本練習卷或解答本，方便帶到學校下課翻閱。

## 📈 高于翔的提分計畫（3步穩拿100分）
1. **第一步（先搞定6大弱點）**：點進「錯題死磕精攻」，將 6 道變形題全數刷至綠色全對。
2. **第二步（全卷滿分驗收）**：點進「原卷全真模擬考」，做一次全部 25 題，目標直衝 100 分。
3. **第三步（統測高分超前部屬）**：下課或放學前刷 10 題「統測歷屆衝刺題庫」，打下穩固基礎！
